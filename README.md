# Step-by-Step QR Code Generator
![QR Code Demonstration](header.png)

## Builds
1. **Executable**: You can find `.exe` in the `_export` folder.
2. **Web Version**: You can find it on [my website](https://sortofschool.org/tools/qr/)

## Important Notes
- Follow buttons from top to bottom. Skipping steps may lead to incorrect representation of the QR code.
- Built with Godot v3.5.1
- Supports only Version 1 of QR codes (21x21 matrix size)
- Operates only in byte-mode
